The Dialer is live — file areas, the hunt, a door game, node chat, moderation, and the release

- **The whole town answers now.** Three public boards — The Rusty Diskette (555-2323), Night Circuit (555-8008), and The Foundry (555-4477) — each with their own sysop, boards, files, and voice, plus a fourth number nobody posts. Dial the breadcrumb chain (Grapevine post → Night Circuit → the scanlog → The Foundry → wf-7's ghost-site story → a credential) and it terminates at PROJECT LODESTONE: a DOE seismic terminal that has been listening, unattended, since 1983 — 300 baud only, exactly as the scanlog warns; dial faster and the carrier won't train. It logs your handle in the visitors book and registers you as an event. That's the screenshot.
- **File areas, for real.** Every board has a file area backed by D1 (text inline) and R2 (dithered images). Upload `.txt`/`.md` in the line editor or an image the client dithers to 16-color CGA before it leaves your machine; the server verifies the PNG rather than re-dithering it. Downloads run a fake XMODEM progress bar at baud speed and spend a ratio credit — upload one to unlock three, refused in-fiction at zero. Three uploads a day.
- **The community layer is moderated.** Every post and upload passes an LLM check before it's visible; a rejection is refused in the sysop's voice, and if the moderation seam is down the write is held hidden rather than published (never fail-open). A nightly Workers cron re-audits held content, hard-deletes what's condemned (R2 object first, then the row, then orphan R2 objects), trims the score tables, resets the daily budgets, and — when it cleaned anything — leaves a canon-voiced "took out the trash" note on the board.
- **`[W]ho's online`, `[C]hat`, and the clock.** The board's Durable Object now runs node chat (ephemeral, like a real node) alongside presence, and enforces the 45-minute daily connect-time budget: warnings at 10 and 1 minutes, and `TIME'S UP` drops carrier. Used minutes flush to D1 so the budget survives a redial.
- **The hunt.** Any `555-XXXX` you see on screen — canon or a real caller's post — is filed in the Phonebook as `?UNVERIFIED?`; dialing it in verifies it. The Autodialer sweeps a 100-number block of the exchange (one a night — the phone company notices), printing `VOICE / BUSY / NO ANSWER / CARRIER` and filing found carriers. There's a tiny door game (Grim Corridor) with a real server-side high-score table, a hidden Back Room reached by typing `WEATHER` at the menu, and `[Y]ell for sysop` answers in the sysop's voice.
- **Persistence and preferences.** Progress (handle, found numbers, verified systems, scanlogs, door score) lives in AppData `progress.json`, alongside a human-readable `PHONEBOOK.TXT` for anyone browsing in Finder. A new Preferences dialog sets default baud and phosphor tint (amber/green/white) and reaches the OS master volume/mute; the menu bar's Hang Up, Phonebook, and Autodialer reach the window through a module store. The whole single-player spine — the chain, LODESTONE, the door, the Back Room — works fully offline in LOCAL MODE.
- **Storage.** Four new D1 migrations seed the two new boards' canon and file areas and add `canon`/`pinned_rank` to `files`; self-hosters run `wrangler d1 migrations apply dialer-db --remote` (0004–0007) with the deploy. Moderation rides the existing site LLM key; no new secrets. The app flips from `coming-soon` to released — zero OS edits, entirely a manifest entry, its components, and its own `/api/dialer/*` routes.
