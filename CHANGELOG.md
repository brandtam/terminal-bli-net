# Changelog

All notable changes to Terminal will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.0 - 2026-06-03

### Added

**Establish the Terminal baseline release**

- Browser-resident TerminalOS desktop with Finder, Dock, menu bar, window manager, app host, Computer Store, and Terminal HD.
- Manifest-driven app registration for system and store apps, including app metadata, windows, menus, About panels, and document handlers.
- Local browser persistence using localStorage for the filesystem manifest/preferences and IndexedDB for blob-backed file bodies.
- Backup/restore, document routing, and app/add-on architecture documentation.
